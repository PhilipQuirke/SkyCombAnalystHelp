# [SkyComb Analyst](https://github.com/PhilipQuirke/SkyCombAnalystHelp/blob/main/README.md) Executable Installation

## Overview
SkyComb Analyst can be installed using an executable installer file. This page details how to download and run the installer.

## Downloading the Installer
The latest SkyComb Analyst installer executable is currently provided by SkyComb staff on demand.

## Running the Installer
SkyComb Analyst is distributed as a ClickOnce package.

To install:
1. Open the provided installer folder from SkyComb staff.
2. Double-click `setup.exe`.
3. Follow on-screen prompts to complete installation.
4. Start SkyComb Analyst from the Start Menu.

## Notes
- If an older version is already installed, uninstall it first from **Windows Settings > Apps > Installed apps**.
- Current packages include required runtime files (including DJI and GDAL-related dependencies).
